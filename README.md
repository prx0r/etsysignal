# roast.pet

Make your pet roast someone.

Upload a few photos. Tell us the gossip. We turn your pet into a comedian and send you a personalised birthday roast.

Every pet you create becomes a Pog — a character you can bring back for new sets, gifts and performances.

## What We're Building

1. **Roast.pet** — Consumer storefront (Etsy)
2. **Pog** — Persistent pet character system
3. **Pog.pet** — Character home/profile
4. **FreakTown** — Performance engine (backend)

## Quick Start

```bash
python3 roast/gift_roast.py roast/demo_orders/buster-001/
```
