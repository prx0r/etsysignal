# Output Spec

## Main Deliverable: Roast Video

### Format
- Duration: 30-60 seconds
- Aspect ratio: 9:16 (phone-first)
- Resolution: 1080x1920
- Frame rate: 30fps
- Codec: H.264 MP4

### Visual Scene
- Comedy club / spotlight / mic stand
- Pet avatar at center (animated)
- Subtitles (bottom third)
- Lower-third with pet name
- Birthday banner/occasion tag

### Audio
- Voiceover (TTS or pre-recorded)
- Background music (optional)
- Sound effects (laughs, applause)

## Thumbnails

### Cover Image
- 1080x1080
- Pet avatar in comedy pose
- Text: "{pet_name} Roasts {recipient_name}"
- Birthday theme

### Poster (optional)
- A3 size
- High-res artwork
- For physical printing

## Card (optional)
- A5 size
- Front: Pet avatar
- Inside: Roast text
- Back: Brand logo
