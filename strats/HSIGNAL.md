# hsignal — Etsy Canonical Plan

## Strategy

**Brand tone:** UK-first (football, banter, absurd pet humor)
**Sales market:** UK + US from day one
**Don't build separate stores** — suppliers handle logistics

## Etsy SEO (from 100-shop study)

- Title: 130+ chars, primary keyword first
- Tags: All 13, comma+space separated
- Photos: All 10 slots, flatlay mockups
- Video: 49/100 top sellers use it
- Shipping: Under £6 (Etsy prioritizes)
- Sales: 25%+ off (93/100 top sellers)

---

## Key Takeaways

1. **Volume wins** — 1,000+ listings, 5+ products
2. **Sales create urgency** — 25%+ off
3. **Pricing is strategic** — low-price variants
4. **Personalization is huge** — 66% of top sellers
5. **SEO matters** — 130+ chars, all 13 tags
6. **Professional presentation** — mock-ups, videos
